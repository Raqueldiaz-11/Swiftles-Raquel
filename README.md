# swiftles

Página web base para empezar a diseñar y editar un sitio web paso a paso.

## Cómo abrirla

Hay dos opciones:

1. Abre directamente `index.html` en el navegador.
2. O ejecuta un servidor local desde la carpeta del proyecto:

```bash
python -m http.server 8000
```

Luego visita: http://localhost:8000

## Archivos principales

- `index.html` → estructura de la página
- `styles.css` → estilos visuales
- `script.js` → interacciones pequeñas

## Personalización

Puedes ir modificando:

- textos y secciones en `index.html`
- colores y spacing en `styles.css`
- comportamiento ligero en `script.js`
